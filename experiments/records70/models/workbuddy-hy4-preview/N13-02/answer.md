### 1.3 2026 年规则变了，这三件事你必须先知道

这一届赶上了近几年改动最大的一届。用去年的老经验（"夏令营拿优营 = 保送"）来排你的时间表，会直接排错。

**变化一：选拔性夏令营大面积取消，"夏令营兜底"这条路没了。**

教育部明确严禁高校借助夏令营提前选拔生源、严禁夏令营活动与招生选拔挂钩之后，清华率先取消保研夏令营，人大、中传、北航、中央民族等多所 985 同步关停。同济、浙大、上交等保留了暑期活动的院校，也**彻底剥离了考核环节**，只做宣讲、学术讲座、师生沙龙，**不再设优营证书，也不再有任何优先录取权利**。

> 对你的直接影响：不要再把 5–7 月当成"夏令营冲刺期"来规划。那个窗口的产出已经从"锁定录取"降级为"混个脸熟"。

**变化二：预推免大幅前置，成为唯一的真正主战场。**

头部院校预推免时间全面提前，而且提前的幅度是"两个月"这个量级：

## 4. 科研：不追求"发表"，追求"能讲清楚"

### 4.1 先接受一个现实约束

你时间有限，**不可能从零发一篇 SCI 或 IEEE Trans**。所以策略必须换：不是"发论文"，而是**"造一个能讲 10 分钟的完整故事"**。

对预推免来说，这两件事的价值差距没有想象中那么大——一个有实物样机、有仿真数据、能说清"我做了哪一步、为什么这么做、结果如何"的项目，在面试里的说服力往往超过一篇挂名水刊。

### 4.2 最优路径：立刻进组，只做一小块

**这周就去做的一件事：找本院一位有在研课题的老师，进组。**

选老师的三个标准（按重要性排序）：

1. **有在研课题且愿意带本科生**（这比老师名气重要得多）
2. **方向与你专业贴合且容易出成果**——优先机器人、智能制造、机电控制、结构优化这类机械学生能快速上手的方向
3. **能给你一个"完整的小块"**——文献调研 → 建模/仿真 → 实验 → 数据 → 报告，从头到尾走一遍

哪怕起点是"帮师兄跑仿真、处理数据"，只要你能说清楚自己在其中的判断和贡献，就成立。

| ★★★ | **实用新型专利 / 发明专利受理通知书** | 2–4 个月 | 广州大学加分认"学生第 1 完成人，或导师第 1、本人第 2"。发明授权周期长，但**受理通知书在简历上同样算数** |
| ★★ | **软件著作权** | 1–2 个月 | 周期短，机械仿真/控制类程序容易申请，是性价比很高的补位项 |

| ★ | 普刊 / EI 会议论文 | 3–6 个月 | 可以做，但**警惕水会**，宁缺毋滥 |
| ✕ | 核心期刊论文 | 6 个月+ | 周期太长，**不要作为主目标** |

### 4.4 红线

**不要买论文，不要挂名水刊，不要编造经历。**

理由不只是道德层面，而是纯粹的风险收益问题：预推免面试老师会就你的项目深挖三到五个技术细节，一问三假直接出局。而且现在整个推免生态的信任已经非常脆弱——学生"囤备胎"、导师"放鸽子"、导师因个别学生失信而拉黑整个学院生源的情况都在发生。**你的每一份材料，都是在为广州大学机械学院的下一届学弟学妹背书。**

## 5. 竞赛：只做能闭环的，不新开战线

### 5.1 机械专业真正值钱的竞赛清单

参照华南理工大学机械与汽车工程学院、南方科技大学机械与能源工程系的推免竞赛认定清单，机械方向认可度最高的赛事是：

| 赛事 | 备注 |
|------|------|
| **全国大学生机械创新设计大赛** | 公认机械类含金量最高，第 12 届常规赛全国决赛 2025 年 10 月在哈工大举办，另有数字孪生设计挑战赛赛道 |
| **中国大学生工程实践与创新能力大赛**（原工程训练综合能力竞赛） | 全国赛特等奖级认定 |
| **全国大学生数学建模竞赛**（9 月初国赛）/ **美赛**（2 月） | 通用性强，认可度极高，且出结果时间可控 |
| **中国国际大学生创新大赛**（原"互联网+"） | 广州大学 A 类赛事，加分权重最高 |
| **"挑战杯"全国大学生课外学术科技作品竞赛** | 广州大学 A 类赛事 |
| **全国大学生机器人大赛 RoboMaster / RoboCon / 中国机器人大赛** | 机器人方向强相关 |
| **全国周培源大学生力学竞赛** | 直接证明力学功底，机械老师很认 |
| **全国大学生智能汽车竞赛** | 机电控制方向加分 |
| **"西门子杯"中国智能制造挑战赛** | 智能制造方向强相关 |
| 全国大学生结构设计竞赛 / 节能减排大赛 | 次一级但仍是国家级榜单内 |

### 5.2 取舍原则

**判断一个竞赛该不该继续投入，只问一个问题：它能不能在 9 月前出结果？**

- ✅ **做**：已经报名、正在推进、9 月前能出结果的比赛
- ❌ **不做**：现在从零组队、11 月才出结果的新比赛——**在 2026 年申请季里这是负收益**

### 5.3 一个反直觉但很重要的点

广州大学的加分规则是：A 类赛事国家级最高等奖 +5 分，前 5 位成员按 100% / 80% / 60% / 40% / 20% 折算。**如果你是团队第 4、第 5 成员，校内加分几乎可以忽略。**

**但外校老师不看你加了几分，他只问"你做了什么"。**

所以：

- 争取在团队里承担**核心设计 / 建模 / 仿真 / 控制**角色，而不是打杂、做PPT、跑腿
- 确保你能独立讲清楚：整体方案是什么 → 你负责哪一块 → 关键参数怎么定的 → 遇到什么问题 → 怎么解决的
- 一个"省级二等奖 + 你是核心建模人"，在面试里的分数高于一个"国家级一等奖 + 你说不清自己干了啥"

### 6.2 导师套磁：双非冲 985 性价比最高的动作

〔隐私删节：精确背景、项目细节、关联身份线索或其推导；原文私有保存。〕

**时间窗口（2026 年要往前挪）：**

- **6 月（首选）**：对应往年"5–6 月夏令营开启前"的黄金窗口。导师当年招生名额已定，有精力看简历。**2026 年预推免 7 月就开，所以 6 月必须完成第一轮。**

**正确顺序（很多人搞反了这一步）：**

1. 查目标学院导师名单 → 看研究方向、近年论文、是否招推免生
2. **精读导师近 1–2 篇代表作**，提炼出你真正感兴趣的点
3. ⚠️ **先完成该院校预推免系统的报名、拿到报名编号，再发自荐邮件**——导师如果想留意你，需要在学院系统里查到你的报名信息。**没报名就套磁基本无效。**
4. 发送邮件（工作日上午 9:00–11:00）
5. 等 5–7 天，无回复礼貌跟进一次，仍无回复换下一位

**邮件规范：**

- 标题：`预推免自荐 | 广州大学机械 - 姓名 - 已报名贵院预推免`
- 正文 **300 字以内**，结构：自我介绍（学校/专业/排名/英语）→ 针对性表达兴趣（**具体点名导师的哪个方向、哪篇论文，不要写"我很感兴趣"这种空话**）→ 个人亮点（科研/竞赛，突出与课题组方向的匹配）→ 询问今年是否还有推免名额 → 致谢 + 附件说明

- 不要发超大附件、不要发压缩包

**四条禁忌：**

1. ❌ 群发模板邮件——一眼就能看出来，直接被忽略
2. ❌ 同一学院同方向同时联系多位老师——会撞车

4. ❌ 夸大经历——导师很容易看穿

**最后一句要记牢：导师口头说"欢迎报考" ≠ 拿到录取。** 最终还是看预推免复试成绩，导师意向只是加分项。

## 7. 面试与专业课：机械方向的必考清单

面试是可以短期突击、且确定性极高的一块，不要因为"我成绩好"就跳过。

### 7.1 专业课必考范围

| 板块 | 具体内容 |
|------|----------|
| **力学（最重要）** | 理论力学（静力学、运动学、动力学核心概念）+ 材料力学（应力应变、强度理论、弯曲扭转）。**这是机械保研面试最基本的考察指标** |
| **机械基础** | 机械原理（机构运动分析、凸轮/齿轮/连杆机构）、机械设计（零件设计计算、强度校核） |
| **软件能力** | CAD：AutoCAD / SolidWorks / UG-NX / Creo / CATIA，**至少精通一种**；CAE：ANSYS / ABAQUS / ADAMS / COMSOL，掌握一种即可；编程：MATLAB/Simulink、Python、C/C++（嵌入式） |
| **项目答辩** | 你的科研/竞赛故事 |
| **英文** | 自我介绍 + 专业文献朗读翻译 |

### 7.2 项目答辩：五段式 + 三个预埋细节

把你的科研/竞赛经历整理成固定结构：

```
问题（要解决什么）
  → 方案（为什么这么选，对比了什么）
  → 我的贡献（具体到某一步，用第一人称）
  → 结果（用数据说话：精度提升多少、效率提升多少）
  → 反思（如果重做会怎么改 —— 这一条最能体现科研素养）
```

然后**主动预埋 3 个可能被追问的技术细节**，并把每个细节准备到能解释原理的程度。老师追问时你答得上来，印象分会非常高。

### 7.3 英语口语单独练

1 分钟自我介绍 + 3–5 篇目标导师论文摘要的朗读与口译。**突击一周就有效果，不要拖到最后三天。**

### 8.2 你的三档配置

| 档位 | 建议数量 | 定位 |

### 8.3 2026 年必须调整的两个策略

**① 必须海投，不能"精选投递"。**

原因是结构性的：**"双一流"高校占据全国约 80% 的推免名额，而占本科高校总数约 80% 的普通院校只拿到约 20%。** 顶尖高校热门专业的推免占比普遍突破 70%，部分方向甚至 85% 以上。这意味着名额增长对你是"无效涨幅"。

同时由于优营超发、按总成绩排名录取，往年的"保底校"今年可能已经换人了。**判断一所学校能不能兜底，不能只看院校层级，要结合当年招生名额、专业报录比、生源背景、导师留人政策综合判断。**

今年的策略已经从"精选投递"变成"**海投对冲**"。

**② 保底校要重新评估，不要按去年的经验填。**

- 往年的保底校，今年可能因为保内名额增加而收紧外保
- 优先选择**明确公示往年接收外校生源**的院校
- 本校这一档一定要真的投、真的确认，不要因为"想冲外校"而放弃本校兜底——2026 年放掉本校最后落空的情况不少
