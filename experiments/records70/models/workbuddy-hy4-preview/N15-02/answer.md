## 一、一句话结论

**本轮不要以"发表论文"为目标，要以"有一篇能讲清楚的研究工作 + 一个不掉下来的排名 + 一套按时投出去的材料"为目标。**

时间分配的基准盘是：**专业课与排名 45%｜材料与信息战 30%｜科研收尾 15%｜英语口语 10%**，并按阶段动态调整。

支撑这个结论的三条原则：

1. **不可恢复的事情优先于可延后的事情。** 报名截止日错过就没了，论文晚两周改不影响大局；期末考砸会直接动摇你最硬的护城河。
2. **本轮科研的正确产出形态是"工作论文"，不是"发表"。** 法学 C 刊、集刊的审稿周期普遍在半年以上，且本科生独发难度极高。推免季内从零投稿到见刊，现实概率很低。把目标从"发表"降级为"成型且可答辩"，你的科研投入才有转化率。
3. **无论文在法学保研里不是致命伤，但"讲不出研究经历"是。** 法学考核（尤其面试）看重的是问题意识、文献脉络、论证逻辑和临场表达。一篇扎实、你能应对追问的未发表习作，价值远高于一篇你讲不清来龙去脉的挂名水刊。

## 四、分阶段执行方案

### 阶段 A｜启动期（章程未出、报名未开）

**配比**：材料与信息 35%｜专业课 35%｜科研 20%｜英语 10%

**核心动作**

1. **建院校追踪表**（Excel 即可，这是整个推免季最重要的工具）。字段建议：院校 / 学院 / 具体方向 / 报名开通日 / 截止日 / 材料清单（成绩单格式、排名证明模板、个人陈述字数、推荐信封数与提交方式、是否需邮寄纸质）/ 考核形式（笔试、面试、英文环节占比）/ 上一年入营与录取情况 / 招生办联系方式。**法学各校考核形式近年在变化**（夏令营、预推免、九月正式推免的比例各校不一），务必以 2026 年最新公告为准，不要照搬往年经验。
2. **跑行政流程**。成绩单、排名证明、外语证明、获奖证书扫描件——这类材料有行政周期（盖章、教务处排期），提前两周启动，不要卡截止日。
3. **提前一个月联系推荐人**。给老师一个素材包：你的成绩单、想突出的 3 个点、代表性习作、目标院校与方向清单、以及每所学校的截止日。别让老师从零写，也别指望暑假能找到人。
4. **科研：只做盘点与挑选**。把做过的项目、课程论文、学年论文、大创报告、调研报告全部列出来，挑出**最有潜力的 1 篇**（判断标准是"有明确问题意识"和"你能讲 10 分钟"），其余封存。

**本阶段产出物**：院校追踪表 v1、全部行政类材料就位、推荐人已口头确认、1 篇待打磨的习作。

### 阶段 B｜夏令营报名与参营

**配比**：专业课与面试准备 40%｜材料投递与打磨 30%｜科研 15%｜英语 15%

**核心动作**

1. **文书做"母版 + 变体"**。一份母版简历、一份母版个人陈述，按院校替换"方向匹配段"——具体说明为什么是这个学校、这个方向、这位导师。同质化海投在面试里会被"为什么选我们"直接问穿。
2. **专业复习从"通读教材"切换到"框架 + 案例 + 争点"三层法**：
   - 框架层：每个核心部门法能默写出体系骨架（民法总则—物权—债—侵权；刑法总论—分论；宪法—行政法；民诉/刑诉；法理）。
   - 案例层：每个部门法准备 2–3 个案例，优先指导性案例与年度热点案件。
   - 争点层：每个部门法准备 3–5 个"我能讲 10 分钟"的专题，包含通说、反对说、你的倾向与理由。
   - **本年度新修法律与重要司法解释请自行核实并纳入**（这类内容几乎是面试必问区，也最容易拉开差距）。
3. **面试模拟优先于笔试刷题**。法学考核以面试为主，且面试的提分速度快于笔试。找同学或老师做 mock，录音回听，重点修"卡壳"和"答非所问"。
4. **科研：本阶段把选中的那篇打磨成 6000–10000 字的工作论文**，配一页纸摘要（研究问题 / 文献脉络 / 论证路径 / 结论 / 创新与不足）。同时准备一份"追问应对清单"：这篇文章最可能的反对意见是什么？你最不确定的一环在哪？

### 阶段 C｜预推免

**配比**：面试与专业 45%｜材料 25%｜英语 20%｜科研 10%

**核心动作**

1. **复盘夏令营**：把被问住的问题全部记下来，逐条补全。夏令营问过的问题在预推免会换一所学校再问一次。
2. **科研止损点（关键）**：设定一个明确的决策日（建议不晚于 8 月底）。届时若稿件仍未进入外审或未被接收，**立即停止投入**，转为"代表性习作"放进材料包，把释放的时间全部转给面试模拟。继续等下去是本轮最典型的沉没成本陷阱。
3. **补投与扩面**：根据夏令营结果调整梯度，该加保底就加，不要硬扛。

### 阶段 D｜九月正式推免

**配比**：面试 50%｜系统与志愿策略 30%｜英语 15%｜科研 5%（基本只做"讲清楚已有成果"）

**核心动作**

1. 确认推免资格落袋（再次核对综合排名口径与名额）。
2. 研究国家推免系统的填报规则与时间节奏（志愿数量、锁定与解锁机制、待录取确认时限），**并提前想清楚志愿梯次与取舍顺序**——系统开放后的决策窗口很短，现场想一定出错。
3. 科研彻底转为"讲述"：确保你能用 3 分钟讲清你的研究，且经得起追问。

## 五、冲突时的取舍规则

当几件事撞在一起，按下面从高到低砍：

1. 期末考试 / 任何影响综排的课程 → 最高优先级，不可让位
2. 报名截止日 → 不可恢复，优先于一切非截止事项
3. 面试模拟 / mock → 转化率最高，优先于论文修改
4. 材料打磨 → 优先于科研
5. 已有论文修改 → 优先于任何新动作
6. **新开题、新项目、新方向 → 本轮一律不做**

一句可记忆的版本：**保排名 > 赶截止 > 练面试 > 改论文 > 别开新坑。**

## 六、赛道与梯度建议

**赛道选择**：无论文的情况下，**学硕与法硕（法学）混申**是容错率更高的策略。学硕看重论文与方向匹配度，你的科研成果形态相对吃亏；法硕（法学）更看重综合素质与英语，你的排名和六级在这里更占优。具体各校当年招生方向与名额需自行核实。

**梯度设置**：必须包含至少一个"几乎确定能接住你"的保底选项（本校是最自然的保底，但仍需确认当年本校推免接收政策与名额）。只有冲刺档而没有保底档，到九月系统会极度被动。

**可被激活的"隐形加分项"**（性价比高于临时赶论文，若有请重点包装）：模拟法庭/辩论赛获奖、法律诊所、法院检察院或律所实习、法律援助、调研报告、参与课题的阶段性成果。**材料中的"代表性学术成果"通常不限于已发表论文**，未发表的课程论文、大创结项报告、调研报告、模拟法庭书状往往都可以提交——请按各校要求确认。

## 七、七个常见坑

1. **排名翻车**。最容易翻车的地方不是专业课，而是体测、思政类课程、选修课和综合素质加减分。搞清楚综排口径，比多写一篇论文重要十倍。
2. **错过截止日**。报名窗口常常只有 7–15 天，且各校时间不一。追踪表不是可选的，是必须的。
3. **临时找推荐人**。老师暑假普遍不在校，临近截止才联系大概率拿不到。
4. **论文贪大**。新开题 + 写长文 = 既发不出来又没复习。
5. **投水刊 /  predatory 出版物**。法学老师对这个一眼看穿，反而是负面信号，宁可不投。
6. **文书同质化**。个人陈述不针对院校，面试被"为什么选我们"问穿。
7. **只冲顶尖，没有保底**。这是九月系统开放后慌乱的唯一原因。

## 四、四条具体调整

### 调整一：大创主持身份，写法要换

材料里不要再用"参与科研项目"这类模糊表述。规范写法应包含：**项目级别（国家级/市级/校级）· 角色（主持）· 立项时间与状态 · 你的具体分工与已有产出**。

若未结项，明确标注"（在研）"，不要含糊让人误读为已结项——这在面试里被追问出来是诚信问题，代价远大于收益。

### 调整二：把时间从"写论文"转到"给论文做压力测试"

你现在的风险不再是"没有论文"，而是**"有一篇经不起追问的论文"**。"参营用"的材料往往带有赶工属性，这在面试里很危险——老师一旦顺着你的论点追问两轮，赶工的痕迹会立刻暴露，而且这比"没有论文"扣分更重。

具体做法（这部分时间算在科研板块内）：

- 准备 3 分钟版 / 30 秒版两个长度的口头陈述，脱稿能讲。
- 写一份**追问清单**并逐条准备好答案：核心论点的一句话表述 · 文献上谁持相反观点 · 你的论证最薄弱的一环在哪 · 这个结论的适用边界 · 如果重做会改哪里。
- 找一位能提问的老师或同学做一次"对抗性问答"，不是让你复述，是让他打断、质疑、追问。

### 调整三：英语从 10% 提到 18%，是这次最重要的动作

理由已在表中说明。落到具体动作上，法学考核的英语环节通常不是"聊天"，而是这几类：

- 1 分钟英文自我介绍、3 分钟英文的研究方向陈述（这两项可以预先写死并练熟，性价比最高）
- 英文法律材料的阅读与当场概括
- 常见英文问答：为什么选这个方向、你的研究打算怎么做、最近读了什么书

## 六、一处需要你澄清的歧义

"已经写过参营用的论文材料"有两种读法，对应的阶段判断和方案侧重完全不同：

- **读法 A：材料已完成，尚未用于投递** → 你大概率在 A 段末/B 段初，科研按 12% 执行，重心是打磨与投递。
- **读法 B：已用这篇材料参过营** → 夏令营已投过，你大概率在 B 段末或 C 段。此时**科研应进一步压缩到 5–8%**，只保留讲述演练，释放的时间全部给预推免的面试与英语——因为下一场考核看的是你现场怎么说，不是材料上多一行字。

请确认是哪一种。如果是 B，上面第三节的表格需要再往下调一档。
