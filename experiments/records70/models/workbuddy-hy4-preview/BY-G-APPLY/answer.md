### 1.2 三个关键判断

**判断一：你的核心矛盾不是"能不能申"，而是"六级卡不卡"。**

我核查了各单位的招生章程，生信方向的英语门槛大致分三档：

- **A 档（卡 470）/ 可豁免**：清华大学 CLS 项目 —— 四级≥500 或六级≥470；**但章程第⑤条明确：以第一作者或并列第一作者在报考学科相关期刊或会议发表（含已录用）英文学术论文，可等同满足外语要求。**
- **B 档（卡 460）**：浙江大学 LSI（生命科学研究院，直博）、浙江大学爱丁堡大学联合学院（ZJE，直博）—— 六级≥460 或托福≥80 或雅思≥5.5。
- **C 档（卡 425，或无硬性分数）**：上海交通大学生命科学技术学院（CET6≥425）、中科院上海营养与健康研究所（CET 六/四级 425 分以上）、中科院北京基因组所（国家生物信息中心，表述为"外语程度良好"）、中科院生物物理所、国科大杭州高等研究院、上海科技大学（仅要求过四级或校级英语水平测试）、南方科技大学、西湖大学。

**这意味着：425–449 分不会封死你的路，但会把"浙大系直博"整条线卡掉，并让你在清华 CLS 的常规通道外。** 所以下面第 1.3 节的两件事必须在申请季前做完。

**判断二：SCI"在投"是张半兑现的支票，必须抢在申请前兑现。**

"在投"在材料里只能写 `under review / under revision`，无法计入"已发表成果"，面试还可能被追问"到底投的几区、一审结果如何"。但一旦拿到 **accepted**，它同时做三件事：①变成硬成果；②**解锁清华 CLS 的英语豁免**；③在华中科技这类"其他院校考生需以一作正式发表 SCI"的条款下直接把你从"不满足"变成"满足"。

**判断三：湿实验 + 大创是隐性资产，别浪费。**

只做干实验的人容易在"数据怎么来的"上露怯。你有湿实验背景，意味着你理解测序建库、批次效应、噪声来源——这在生信面试里是**高区分度**的加分项。大创则证明了项目执行力。这两项要在个人陈述里主动"翻译"成干实验能力，而不是平铺直叙。

### 1.3 申请季前必须完成的两件事（按优先级）

| 优先级 | 事项 | 目标 | 最晚完成时间 |
|---|---|---|---|
| **P0** | **把 SCI〔分区隐去〕一作从"在投"推到"录用(accept)"** | 拿到接收函/录用证明 | 2027 年 5 月前（赶夏令营投递） |
| **P1** | **六级刷分** | 目标 **470+**（解锁清华 CLS 常规通道、浙大 LSI/ZJE） | 2027 年 6 月场次（成绩 8 月出，赶预推免） |

刷六级的战术建议：425–449 说明基础不差但应试策略有短板，重点攻听力（占比 35%）和阅读速度。如果刷分失败，退路是考 **雅思 6.0 / 托福 90**——这两项在几乎所有学校都被认可，且出分快、可多次考。

## 四、投递策略

### 4.1 三档并行的兵力分配

| 阶段 | 投递量 | 主要目标 | 精力分配 |
|---|---|---|---|
| **夏令营（5–7月）** | 20–30 家 | 攒优营、练面试、摸清行情 | 60% |
| **预推免（8–9月）** | 15–20 家 | 主力战场，多数名额在此释放 | 30% |
| **九推（9月下旬）** | 3 个志愿 | 终局博弈 | 10% |

**核心原则**：
1. **不要只投华五。** 华五直博录取率极低，且你的六级是硬伤。把 60% 的精力放在中科院系统 + 华科/武大/中山这一档，才是理性的期望值最大化。
2. **科研院所优先。** 中科院系统（国家生物信息中心、上海营养与健康所、生物物理所、杭高院、深圳先进院）在你这个画像下**性价比全面高于华五校本部**：英语门槛低、211 友好、生信对口、补助高、科研密度大。
3. **每条线都找好"第二落点"。** 例如投浙大 LSI（460 卡线）的同时，必须同时投浙大 ZJE 硕士或浙大其他院系作为备选。

### 4.2 关于"直博"的严肃提醒

你说"优先考虑华五及以上直博"——我支持，但必须把风险讲清楚：

- **直博是 5 年（部分 6 年）的单程票。** 中途退出一般只能拿本科学历，没有硕士学位。
- **导师决定一切。** 直博的成败高度依赖导师人品与方向，套磁时的"反向尽调"（问组内学生、查毕业去向、看近三年发文）比什么都重要。
- **你的优势恰恰在直博。** 排名前 10% + SCI 一作 + 湿实验背景，在申请硕士时会被"卷成绩"淹没，但在直博评审中，科研潜力和实验训练是更被看重的维度。
- **建议**：T1 档全部投直博，T2/T3 档"直博 + 学硕"混合投递，确保至少有一个硕士层次的保底。

### 4.3 关于"只做生信干实验"的匹配建议

你的目标非常明确，这在申请中是**加分项**（方向清晰的人更受导师欢迎），但也要注意两点：

1. **避开"名义生信、实际湿实验"的组。** 申请前一定要问清：组内学生日常是写代码还是养细胞？近三年发的论文里，第一作者是做分析还是做实验？
2. **干实验赛道内也要选子方向。** 建议你在以下三条中选一条主线：
   - **算法/方法学**（开发新工具，对数学要求高，出路：学界、AI for Science 公司）
   - **数据分析/组学应用**（用现成工具做生物学发现，对生物学理解要求高，出路：医院科研岗、药企）
   - **医学/队列生信**（统计遗传学、生物统计，出路：CRO、药企生物统计，薪资好）

   以你"湿实验 + 大创 + SCI〔分区隐去〕一作"的背景，**"数据分析/组学应用"或"医学/队列生信"是最优解**——入学即可上手，产出快。

### 6.2 直博专项加件

- **《攻读博士学位研究计划》**（1500–3000 字）
- **《直博生导师意向函》** —— 上交系统生物医学研究院等要求**报名前与导师确认并上传**
- 部分院校要求**两位教授（正高）**而非副教授推荐

### 6.3 关于 SCI"在投"怎么写（重要）

**千万不要写成"已发表"。** 正确写法：

```
[1] 作者1, 作者2, ..., 本人（第一作者）, 通讯作者. 论文标题[J]. 期刊名（SCI〔分区隐去〕，IF = X.X）, 状态: Under Review / Under Revision.
```

同时准备好：投稿期刊的分区证明、投稿系统截图、审稿意见与返修记录。**如果能拿到录用函（accept letter），务必立刻更新到所有材料里**——这是你整个申请季最大的一张牌。

### 6.4 材料组织建议

- 所有材料**合并成一个 PDF**，按目标院校要求的顺序排列
- 命名严格按规则（如"27推免-郑州大学-姓名"或"姓名+高校名+ABC"）

- 建立投递台账：院校 / 项目 / 截止日 / 账号 / 密码 / 材料版本 / 结果

## 七、面试准备要点

### 7.1 生信方向高频考点

**编程与工具**
- Python（NumPy / Pandas / Scikit-learn）、R（Bioconductor / ggplot2 / DESeq2 / Seurat）
- Shell / Linux 基本操作
- 常用工具：BWA / Bowtie2 / STAR / Hisat2、SAMtools / BEDTools、MACS3、GATK、Salmon / Kallisto
- 流程管理：Snakemake / Nextflow、Conda / Docker / Singularity

**统计与机器学习**
- 假设检验、多重检验校正（FDR / BH）、p 值与效应量
- 线性回归、广义线性模型、逻辑回归
- 降维（PCA / t-SNE / UMAP）、聚类（k-means / 层次聚类）
- 交叉验证、过拟合与正则化；随机森林、SVM、基础神经网络

**生物学**
- 中心法则、基因表达调控、表观遗传（甲基化 / 组蛋白修饰 / 染色质可及性）
- 常见组学：WGS / WES / RNA-seq / scRNA-seq / ATAC-seq / ChIP-seq / 空间转录组 / 蛋白组 / 代谢组
- 要能说清**每种组学解决什么问题、数据长什么样、主要噪声来源**

### 7.2 你的两个"必考题"

**① "你的 SCI 投了什么期刊？现在什么状态？一审意见怎么说？"**
提前把审稿意见吃透，能说出"审稿人提了哪几点、我们怎么回应"。这比论文本身更能证明你是真做的。

**② "你有湿实验经历，为什么研究生只想做干实验？"**
这是**送分题**——因为你有湿实验背景，你的回答比纯干实验的人更有说服力。建议这样组织：

> 湿实验让我理解了数据是怎么产生的——建库的偏好、批次效应、技术重复的噪声从哪里来。这也让我意识到，我更擅长和更感兴趣的是从数据里提炼生物学规律，而不是操作实验本身。湿实验的训练让我在做分析时不会把数据看成抽象的表格，而会追问每一个信号背后的实验过程。

### 7.3 英语环节

国家生物信息中心的面试中**英语占 30%**，西湖大学有专门英语口试，上交、复旦等也普遍考口语。425–449 分不会让你在这里失分——**口语和笔试是两回事**。准备：
- 1 分钟 / 3 分钟英文自我介绍各一版
- 用英文讲清楚自己的 SCI 工作（重点：问题、方法、结论）
- 朗读并翻译一段目标 PI 近三年论文摘要
