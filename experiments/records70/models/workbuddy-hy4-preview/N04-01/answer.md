### 0.2 2026年这个季度的三个结构性变化（据公开报道与院校通知，务必自行复核）

1. **选拔性夏令营大面积弱化/取消。** 教育部明确严禁高校借助夏令营提前选拔生源、严禁夏令营活动与招生选拔挂钩后，清华等多所高校取消保研夏令营；同济、浙大、上交等保留暑期活动的院校剥离考核环节，只做宣讲与学术沙龙，**不再发"优秀营员"直通offer**。
2. **预推免成为主战场，且时间大幅前置。** 头部院校预推免从往年的8月底—9月，提前到 **6—7月开放报名、7—8月完成大部分考核**（如清华27届推免系统7月1日开放、7月28日关闭）。**"夏令营兜底、预推免补录、九推捡漏"的三段式老经验，今年已不完全适用。**
3. **优营不再等于保底，考核更看科研与实践。** 多校为防止被"放鸽子"超发优营，并明确"按总成绩从高到低录取"，位次靠后的优营会被挤出有效区间；同时直博比例提升、学硕相对收缩，竞赛、论文、专利权重上升。

> **对你最直接的推论：** 你不是"顶尖绩点型"选手（约15%），但你是有真实科研产出的选手。**在"卷绩点"转向"卷科研"的年份，你的相对位置是变好的**——前提是你能把科研讲透、把方向匹配做对、把节奏踩准。

## 一、定位诊断：先看清你手里到底是一副什么牌

### 1.1 硬件盘点与"市场定价"

| 项目 | 你的情况 | 在推免市场里的真实含义 |
|---|---|---|
| 本科院校 | 内蒙古大学（211、双一流建设高校） | **够用不占优**。绝大多数985/中科院所的报名门槛是"双一流/具备推免资格"，你过线；但在初筛时不会给你加分。 |
| 专业排名 | **前约15% ≈ 约15%** | 冲顶尖985化工（天大、浙大、清华等，往年偏好前5%—10%）**有难度**；对学科A类但非顶校、中科院体系、以及"重科研轻绩点"的导师组，**完全够用**。 |
| 英语 | **六级450–499** | **你最明显的短板**。多数院校工科门槛是四级425或六级425，你过线；但热门985在实操筛选中偏好500+。部分院所（如中科院多数研究所）**明文只要求"英语达到国家四级水平及以上"**，对你非常友好。 |
| 科研 | 电池方向 + 〔催化方向〕方向；**EI会议一作**、**SCI〔合作作者〕** | **你最强的资产，且是稀缺资产**。大多数同层次竞争者是"跟着老师干过活"，你是有**署名成果**的。 |
| 竞赛 | 全国大学生化工设计竞赛 | 化工类认可度最高的团队竞赛之一，是"工程实践能力"的硬证据，对**化学工程与技术**（而非纯化学/材料）方向尤其加分。 |

### 1.2 校内推免资格：这是第一道生死线，先算清楚

公开整理的内蒙古大学近年保研率约为 **13%—15%**（其中2025届推免指标516人、保研率13.14%；2024届486人、14.21%；另有来源按不同口径给出14.7%）。你 **约15%** 正好落在这个区间的**边缘偏上**——**有戏，但绝不是稳拿，且化工学院的名额比例与全校平均值未必一致。**

内蒙古大学已公布的推免细则要点（以**当年学院正式文件**为准，务必去教务办核对）：

- **学业门槛：** 按平均学分绩点排名，专业排名不低于本专业**前50%**（这是资格门槛，不是录取线，实际按名额从高到低切）。
- **外语：** 非英语专业 CET-4 ≥ 425；**同等条件下 CET-6 ≥ 425 优先**。你450–499，符合"优先"档。
- **竞赛加分：** 一等奖最高加 **0.15** 学分绩点，二等奖 0.12，三等奖 0.10（需为本科阶段主力成员参加国内权威科研竞赛）。
- **科研论文加分：** 本科阶段**核心期刊独立作者或第一作者**发表与学业相关论文，学分绩点加分最高 **0.15**。**

**这里有一个你必须立刻处理的关键风险：** 你的 **EI会议一作** 是否会被学院认定为"核心期刊"、 **SCI〔合作作者〕** 是否计入加分，都有不确定性（很多学院只认一作/核心）。**行动：本周内带着论文原件、检索证明去学院教务办/推免工作小组当面确认认定口径，并要求书面或邮件答复。** 0.15 的绩点加分，在 约15% 这种边缘位次上，可能就是"有资格"和"没资格"的分界线。

同时确认三件事：
1. 排名用的是 **必修课加权 / 全部课程加权 / 综合测评** 中的哪一种？你的 前约15% 是哪个口径？
2. 学院今年分到多少推免名额？是否有"破格"通道？
3. 大四上（最后一学期）成绩是否计入？**计入的话，最后一学期绝不能滑坡。**

### 1.3 SWOT

**优势（S）**
- 有署名成果（EI一作 +SCI〔合作成果细节隐去〕），在同层次候选人中稀缺；
- 两条科研线（电池、〔催化方向〕）都在能源材料主赛道上，容易讲成一个完整故事；
- 化工设计竞赛提供"工程侧"证据，使你同时具备"科学+工程"双标签，报化学工程与技术比纯化学背景的学生更对味。

**劣势（W）**
- 排名约15%，非顶尖；六级450–499偏弱；
- 无顶刊一作，EI会议+SCI〔合作成果细节隐去〕的"含金量"需要靠讲述来兑现；
- 两条科研线若讲不好，会被问"你是不是什么都做一点、什么都不深"。

**机会（O）**
- 今年选拔性夏令营弱化、预推免前置、科研与实践权重上升，正对你的强项；
- **中科院体系**（化学所、上硅所、过程工程所、大连化物所、理化所、宁波材料所、山西煤化所、成都有机所、青岛能源所等）对科研型选手友好、英语门槛多为四级、招生批次多（以化学所2027级为例：第一批7月17日—8月14日、第二批8月31日—9月9日、第三批9月下旬发布、10月7日前报名），**是你性价比最高的主攻方向**；
- 化工学科A类院校中，**南京工业大学（A）、浙江工业大学（A-）、青岛科技大学（B+）、太原理工（B+）** 等非985强校对科研型外校生更友好。

**威胁（T）**
- 顶尖985化工院系初筛仍看排名/英语，容易被机器筛掉；
- 今年多校面试集中撞期、优营超发，容错率下降；
- 若校内资格落空，推免全盘归零。

### 1.4 战略结论

> **不要去当"绩点不如人但全面发展"的平庸候选人，要去当"方向对口、有成果、能上手"的科研型候选人。**
>
> 三条落地原则：
> 1. **方向先行**：只投"电化学储能 / 光（电）催化 / 能源材料 / 化工过程"相关的导师和方向，宁可降学校档次也不投不对口的组。
> 2. **导师优先于学校**：15%排名的学生，靠"投学校"大概率被初筛；靠"被导师点名要"则能绕过机器筛选。
> 3. **英语避战**：优先选择英语门槛明确为四级/六级425的院所，把英语比拼限制在"能讲清自己的科研"这一项上。

## 二、目标分层：冲 / 稳 / 保（按赛道而非按名气）

### 2.1 选方向的三个落点

| 落点 | 适用 | 你的匹配度 |
|---|---|---|
| **化学工程与技术（0817）** | 发挥化工设计竞赛+工程背景；方向选"化学工艺/工业催化/应用化学" | ★★★★★（最对口，竞赛直接变现） |
| **材料科学与工程（电化学储能、能源材料）** | 发挥电池方向 | ★★★★☆（注意：材料热门，985材料竞争激烈） |
| **化学（催化、物理化学）** | 发挥〔催化方向〕方向 | ★★★★☆（中科院化学所、理化所、大连化物所是天然出口） |

**建议组合：** 主投 **化学工程与技术 + 材料与化工（专硕）**，辅以 **化学/材料** 中与电池、〔催化方向〕直接对口的组。**不要跨到完全无关的方向**（比如转计算机、转金融），那会浪费你唯一的比较优势。

### 2.2 冲稳保名单（建立你的信息台账，建议 20—25 个目标）

**第一梯队（冲，5—8所）——押"导师点名"和运气**

- 化学工程与技术学科评估 **A+**：天津大学、华东理工大学
- **A**：清华大学、北京化工大学、大连理工大学、浙江大学、南京工业大学（A，非985，**其实更接近"稳"**）
- **A-**：哈尔滨工业大学、华南理工大学、四川大学、中国石油大学（北京）、中国石油大学（华东）、北京理工大学
- **B+** 中的强校：上海交通大学、西安交通大学、中南大学、厦门大学、东南大学

> 冲的策略是"**冲导师不冲院系**"：先找到方向100%对口、近三年有接收外校推免生记录、且今年明确有招生名额的导师，拿到口头认可后再正式投递，成功率远高于盲投。

**第二梯队（稳，8—10个）——你的主战场**

- **中国科学院体系（强烈建议重点布局，6个以上）**：
  - 化学所（分子科学、催化、光电材料；2027级推免多批次，英语要求四级及以上）
  - 上海硅酸盐研究所（储能材料、〔催化方向〕材料；国科大系统报名，往年8月中下旬—9月中下旬）
  - 过程工程研究所（化工、能源转化、过程强化；与你的化工背景最贴合）
  - 大连化学物理研究所（催化、电化学储能；体量大、方向全）
  - 理化技术研究所、宁波材料技术与工程研究所、山西煤炭化学研究所、成都有机化学研究所、青岛生物能源与过程研究所、苏州纳米技术与纳米仿生研究所
  - **关键提醒**：化学所等报名条件中涉及"双一流大学/一流学科建设高校"的表述，各批次措辞可能不同，**报名前务必打研究生部电话（如化学所教育处 010-62544602）确认你的院校层次是否符合**，这是5分钟能省掉一个月的事。
- **化工强校（非985但学科硬）**：南京工业大学、浙江工业大学、青岛科技大学、太原理工大学、河北工业大学
- **综合类211/985的化工或材料学院**：郑州大学、江南大学、中国矿业大学、西北大学、西南石油大学、湖南大学、苏州大学、合肥工业大学、福州大学

**第三梯队（保，3—5个）——必须有，且必须真的能兜住**

- **内蒙古大学本校**（化学化工学院、**能源材料化学研究院**）：这是你最可靠的兜底。**务必提前联系本院/本校导师，明确是否有名额、是否愿意接收你，并确认本校关于"取得推免资格后必须填报本校/不得放弃"的规定**（部分高校有此类约束，会影响你的系统填报策略）。
- 内蒙古工业大学（化学工程与技术 B-，本地、录取概率高）
- 其他本区/邻近有推免接收能力的院校（如内蒙古科技大学等，视当年专业目录）

> **"保"不是丢人，是工程思维**：保研这件事的期望值 = 上岸概率 × 学校质量。没有保底的分层，就是把三年积累押在单次博弈上。

## 三、接下来怎么排：分阶段执行时间表

下面按"距系统开放还有多久"给出三档节奏。**请对照今天的日期，直接进入对应阶段，并把前面阶段的缺项在48小时内补齐。**

### 阶段 A｜准备期（系统开放前 8 周以上 / 6—7月）
**目标：资格确认 + 材料包成型 + 导师数据库建好**

- [ ] **校内资格**：找学院教务确认推免细则、名额、排名口径、加分认定（EI会议/SCI〔合作成果细节隐去〕是否算）；拿到**盖章的排名证明**。
- [ ] **材料包一次成型**（详见第六章）：一页简历、个人陈述800字/1500字双版、推荐信2封、成绩单、排名证明、论文首页+检索证明、录用通知、获奖证书、英语证书、作品集。
- [ ] **导师数据库**：用Excel建台账，字段 = 学校/院所、导师、方向、近3年代表作、是否在招、联系方式、投递日期、回复状态、下一步动作、截止时间。目标 **40—60 位导师、20—25 个招生单位**。
- [ ] **英语**：若还有一次六级报名机会（一般6月考试、8月出分，能赶上预推免），**务必报名并集中刷题**；目标只要 500 分即可，性价比极高。
- [ ] **专业课回炉**：化工原理（流体流动、传热、精馏/吸收/干燥、设备选型）、化学反应工程、化工热力学、物理化学（电化学、动力学、表面与胶体）、催化基础。**部分院校预推免有笔试，化工原理和物化是最高频的两门。**

### 阶段 B｜预推免主战场（7—9月，今年已前置）
**目标：用科研叙事 + 导师对接拿下 2—3 个有效offer**

- [ ] **每周节奏**：周一更新各校通知（各校研究生院官网 + 学院官网 + 研招网），周三/周五集中投递与套磁，其余时间准备面试。
- [ ] **投递原则**：冲3、稳6、保3 同步推进；**每个学校只投方向对口的导师/方向**，不要为了凑数投无关方向。
- [ ] **套磁提前于系统**：研招网系统只是走流程，**真正的名额在导师手里**。7月就开始发邮件（模板见第七章）。
- [ ] **面试撞期管理**：今年多校考核集中在同一周。**提前给每个offer排优先级，撞期时果断放弃低优先级**，并在放弃前确认高优先级那边是否真的有戏。
- [ ] **每场面试后 24 小时内**：发感谢邮件 + 复盘记录被问到的问题（你会发现问题高度重复，题库会自己长出来）。

### 阶段 C｜冲刺校准（9月上中旬，系统开放前 1—2 周）
**目标：把offer收敛成"志愿优先级表"**

- [ ] 与所有给你正面反馈的导师**再确认一次**：今年是否有名额、是否愿意接收、是否需要你在系统里第一志愿填报。
- [ ] 排出 **志愿优先级表**（1、2、3 号位+备选），写清楚"如果A校9月22日发复试通知但B校还没消息，我怎么决策"。
- [ ] 完成系统注册、资料填报、缴费（9月18日起即可做，**不要拖到9月21日一起做**）。

## 四、核心章节：把科研优势真正"变现"

这一章是本答卷的重点。**你有成果 ≠ 你会赢**，赢的人是能把成果讲成"这个人来了就能干活"的人。

### 4.1 先解决"两条线会不会显得散"的问题

电池（电化学储能）和〔催化方向〕（能源转化）**不是两条散线，是同一条主线**：

> **"光/电驱动的能源转化与存储"** —— 〔催化方向〕是把光能转成化学能（能源转化），电池是把化学能存起来再放出来（能源存储）。两者共享同一套底层能力：**电极/催化剂材料的设计与合成、结构表征、电化学性能评价、机理分析**。

**一句话定位（背下来，用在所有场合的开头）：**
> "我的本科科研围绕**能源转化与存储中的材料—性能—机理**这条链条展开：一方面做〔催化方向〕材料的设计与性能评价，另一方面做电池体系的电化学行为研究；两段工作让我掌握了从材料合成、结构表征到电化学测试和数据分析的完整闭环。"

**三个版本，都要准备：**
- **30秒版**（群面/自我介绍开头）：上面那句话 + "EI会议一作、SCI〔合作作者〕"。
- **3分钟版**（面试主力）：背景→我做了什么→关键结果→我的独立贡献→为什么适合贵组。
- **10分钟版**（导师深聊/学术报告）：加数据、加对比、加机理讨论、加不足与展望。

### 4.2 成果证据包：每一项都要能"亮出来"

| 成果 | 必备证明材料 | 呈现要点 |
|---|---|---|
| EI会议一作 | 会议全称+主办单位、录用通知、**检索号/DOI/论文集页码**、是否口头报告（oral > poster）、是否获best paper、会议PPT | 强调"**独立完成一个完整工作闭环**：选题—方案—实验—数据—写作—报告"。EI会议一作在本科生里是实打实的加分项，不要自我贬低说"只是个会议"。 |
| SCI〔合作作者〕 | 期刊名、**影响因子+分区（截图）**、DOI、封面/首页、你的具体贡献 | **准备一段30秒的"贡献说明"**："我承担了××的合成与××表征、完成了××组电化学测试与数据处理、参与了初稿××章节的撰写"。**必须和你导师/一作的说法一致**——面试老师可能会追问细节。 |
| 化工设计竞赛 | 赛事全称、主办单位（教育部高等学校化工类专业教学指导委员会）、获奖等级与年份、**你负责的工段**、团队角色 | 这是"工程能力"的证据。**讲出工程味道**（见4.5）。 |

**注意：校内加分和校外申请是两套逻辑。** 你的SCI〔合作成果细节隐去〕和EI会议在校内加分上可能不被认定（4.1节说过的0.15上限与"核心期刊一作"限制），**但对外校导师来说，这些就是你干活能力的直接证据**。两条路都要走，别因为校内不认就觉得白干了。

### 4.3 面试深挖题库（按类别准备，每个问题都写下答案要点）

**A. 科研深挖类（最关键，决定生死）**
1. 你这个工作的**创新点**到底是什么？和已有文献比强在哪？
2. 为什么选这个材料体系/这个组份比例？有没有对照实验？
3. 你用的是什么合成方法？关键参数怎么确定的？
4. XRD/SEM/TEM/BET/XPS/UV-Vis 你都用过哪些？**每条谱图你是怎么看的？** 峰位为什么是这样？
5. 〔催化方向〕：光源功率、波长、催化剂投加量、牺牲剂、量子效率/表观速率常数怎么算的？**怎么排除敏化和自降解？**
6. 电池：充放电曲线怎么看？比容量怎么计算（基于活性物质质量还是总质量）？循环多少圈、容量保持率？**EIS 你怎么拟合？** 赝电容贡献怎么算？
7. 你的数据有误差棒吗？重复性做过几次？
8. 机理部分哪些是**实验证据支持的**，哪些是**你的推测**？（这道题答老实=加分）
9. 这个工作最大的不足是什么？如果重做你会改什么？
10. 你的工作和××文献（老师随口点一篇）相比如何？

**B. 工程与竞赛类**
11. 化工设计竞赛你负责哪个工段？工艺流程是怎么定的？
12. 精馏塔的**回流比、理论板数、塔径**怎么确定？用什么软件模拟（Aspen Plus）？
13. 反应器选型依据（转化率、选择性、热效应、移热方式）？
14. 换热网络是怎么优化的？公用工程消耗怎么算？
15. 经济核算：投资估算、成本、回收期怎么算的？敏感性分析做过吗？
16. 安全与环保：三废怎么处理？有哪些危险源？HAZOP做过吗？
17. 图纸：PFD和P&ID的区别？你画过哪一级？
18. 团队里出现过分歧吗？你怎么解决的？

**C. 专业基础类（笔试+面试通用）**
19. 化工原理：伯努利方程、传热速率方程、精馏的操作线方程、吸收塔高度计算、干燥速率曲线。
20. 反应工程：反应速率与温度的关系（阿伦尼乌斯）、全混流与平推流反应器的区别与选型、催化剂失活。
21. 化工热力学：逸度、活度系数、相平衡判据。
22. 物理化学：能斯特方程、双电层、极化与过电位、Langmuir吸附等温式、半导体能带与光生载流子分离。
23. 专业英语：用地道的英文说出你的课题关键词（photocatalysis, charge separation, band gap, specific capacity, rate capability, cycling stability, EIS, charge-transfer resistance…）。

**D. 动机与规划类**
24. 为什么选我们学校/我们组？（**必须具体到导师的某篇论文或某个方向**，泛泛说"学校好"直接出局）
25. 你读过我们组哪些论文？有什么想法？
26. 读硕还是读博？（今年直博扩招，**建议对直博持开放态度并说清楚理由**，这会显著提升你的录取概率）
27. 研究生阶段想做什么？三年/五年规划？
28. 如果实验一直失败、一年不出成果，你怎么办？

**E. 压力与品格类**
29. 你的排名不是最靠前，为什么觉得自己适合做科研？（**正面回应，讲科研产出，不要道歉式回答**）
30. 你六级450–499，英文文献阅读和写作能跟上吗？（**用事实回击**：我独立阅读了××篇文献、用英文写过自己的论文/摘要、现在可以用英文讲一遍我的工作——然后真的当场讲30秒）

### 4.4 讲好一个实验的标准结构（背下来套用）

> **背景（为什么要做）→ 痛点（现有方法差在哪）→ 我的思路（怎么设计）→ 方法与条件（怎么做的，关键参数）→ 结果（数据+图）→ 对比（vs 文献/对照组）→ 结论（说明了什么）→ 不足与展望（我清楚边界在哪）**

**加分技巧**：每讲完一个结果，主动补一句"**这个结果我当时也怀疑过是不是××导致的，所以我做了××对照实验排除**"。这句话能瞬间把你和"听话干活的本科生"区分开。

### 4.5 化工设计竞赛要"讲出工程味道"

很多同学把竞赛讲成"我参加了比赛拿了奖"，这是浪费。**要讲成工程决策链**：

> "我们做的是××产品的全流程设计。我负责××工段：首先用 Aspen Plus 建立流程模拟，确定反应器形式为××，理由是转化率与选择性/热效应；精馏序列按××规则排序，理论板数××、回流比取××Rmin，塔径由液泛气速反算；换热网络做夹点分析后节能××%；经济核算显示投资××万元、投资回收期××年；安全方面识别了××危险源并做了××防护。"

这样讲，化工院系的老师会立刻把你识别为"能进组干活的人"。

### 4.6 红线：三条绝对不能碰

1. **不夸大作者贡献。** EI一作就是一作，SCI〔合作成果细节隐去〕就是〔合作成果细节隐去〕，说清楚自己做了什么即可。**老师一追问细节就露馅，学术不端是零分且可能取消资格。**
2. **不编造没做过的实验、没用过的方法。** 被问"这个表征你亲手做的还是送测的"，实话实说。
3. **不贬低自己的本科院校和导师。** 抱怨者一律不受欢迎。

## 五、短板修补：六级450–499和排名15%怎么处理

### 5.1 英语（优先级最高的可修补项）

**如果有考试机会**（一般6月考、8月出分，正好赶上预推免）：
- 立刻报名，**目标只定500分**，不做600分的梦。
- 四周集中方案：每天1.5小时——听力真题精听30min + 阅读2篇精读（查词、翻译长难句）40min + 写作模板背诵与仿写20min。
- **500分 vs 450–499分，在初筛机器眼里是两个档次**，这是全季ROI最高的一件事。

**如果已经没有考试机会**（已进入9—10月）：
- **战略避战**：优先投英语门槛明确为"四级/六级425"的院所（中科院多数研究所、部分211），避开把六级500+写在招生办法里的项目。
- **能力对冲**：把"学术英语"练到能自证——
  - 准备 **英文版自我介绍（1分钟）+ 英文版科研陈述（2分钟）**，背到脱口而出；
  - 能**朗读并即时翻译**自己论文的摘要与关键图表说明；
  - 准备个人陈述的英文版（部分院所要求英文材料）；
  - 练10个英文追问的听答（"What's the novelty?"/"What's your specific contribution?"/"Why this material?"）。
- **面试现场补救话术**："我的六级分数不算高，但我的科研工作全程需要阅读英文文献，我独立完成了××篇文献调研并用英文完成了论文写作/会议报告。如果老师允许，我可以用英文介绍一下我的工作。"

### 5.2 排名（不可逆转，但可以优化）

- **把加分拿满**：竞赛获奖、论文认定的材料**按学院要求的格式一次性交齐**，并主动跟进认定结果（一等奖0.15绩点，可能直接改变你的位次）。
- **确认口径**：如果排名有多种算法，了解学院用的是哪一种，看是否存在对你有利的口径（但不要试图钻空子）。
- **守住最后一学期**：若大四上成绩计入推免排名，**任何一门课的低分都可能把你挤出名额**。这一学期的绩点优先级高于一切实习和杂事。

### 5.3 专业课（防止笔试翻车）

- 必看：**化工原理**（占笔试概率最高）、**物理化学**、**化学反应工程**。
- 方法：不做难题，做"能讲清楚"的题——面试笔试更看重概念与推导思路，而不是计算速度。
- 准备一份"**公式与概念速记卡**"，考前一天过一遍。

## 六、材料包：一次做好，全季复用

### 6.1 简历（严格一页，科研栏提到最前）

顺序建议：**教育背景 → 科研经历（2段，占半页）→ 论文成果 → 学科竞赛 → 荣誉奖励 → 技能（仪器/软件/语言）**

写法要点（每条都按"动作+方法+结果"）：
> ✗ 错误写法："参与〔催化方向〕课题研究，协助完成实验。"
> ✓ 正确写法："设计并合成××系列催化剂（××法），通过 XRD/SEM/BET/XPS 完成结构表征，在××条件下实现××降解率/产氢速率，较对照组提升××%；以第一作者发表于××（EI检索）。"

**技能栏务必写具体**：Aspen Plus、Origin、ChemDraw、XRD/SEM/BET/XPS 操作、电化学工作站（CHI）、手套箱、电池组装与测试、ZView拟合等。**这些词是导师的检索关键词。**

### 6.2 个人陈述（准备800字与1500字两版）

五段式：
1. **开头一句话定位**（见4.1的30秒版）。
2. **学业基础**：排名、核心课程成绩、专业训练。
3. **科研经历**（最长，占40%）：按4.4的结构写两个工作，讲清楚**我做了什么、我做成了什么、我学到了什么**。
4. **工程实践**：化工设计竞赛，讲工程决策链（见4.5）。
5. **读研规划 + 为什么是这个组**：**必须点名导师及其具体研究方向**，说明你的经历如何与之衔接，以及你打算做什么。

### 6.3 推荐信（2封）

- **第一封：你的科研指导教师（最重要）**——能证明你的实验能力、主动性、对课题的真实贡献。
- **第二封：专业课教师或竞赛指导教练**——证明学业与工程能力。
- **不要找行政领导写泛泛的推荐信。** 招生老师能一眼看出来。
- 给推荐人提供一份"素材清单"：你的成果列表、你希望被强调的3个点、对方学校的截止时间与提交方式。
- 职称要求：**副教授及以上**（中科院化学所明确要求"副教授或相当职称以上专家"）。

### 6.4 证件与证明（扫描件规范）

成绩单（教务处盖章）、排名证明（盖章）、四六级证书、身份证正反面（一页A4）、获奖证书、论文首页+检索证明/DOI、录用通知、专家推荐书。

- **所有材料按目标单位要求的顺序合并为单个PDF**，文件命名严格按通知要求（如化学所要求："报考导师姓名/专项名称+本人姓名+本科学校"）。
- 全部扫描件统一 300dpi、彩色、无阴影，存一份网盘备份。

### 6.5 作品集（科研图册，8—12页）

结构：封面 → 个人简介 → 工作一（背景/设计/关键图/结论）→ 工作二 → 竞赛设计（流程图+关键设备+经济核算）→ 技能与仪器 → 成果清单。**在套磁邮件和面试现场都能用**，是你区别于其他候选人的"实体感"。

## 七、联系导师（套磁）实操手册

对15%排名的学生来说，**这可能是整个申请季最重要的一项工作**。

### 7.1 四维筛选法

1. **方向匹配度**（最重要）：看他近3年论文，你的合成/表征/电化学能力能不能直接平移过去。
2. **是否有名额**：看招生专业目录、上年录取名单、组内是否有今年毕业的学生腾位。
3. **是否接收外校推免生**：查上年拟录取名单里有没有外校生源——**没有外校生的组，你投了大概率是陪跑**。
4. **组内口碑**：找学长学姐问毕业要求、补助、作息、师生关系。**别只看帽子和论文数。**

### 7.2 套磁邮件模板（可直接改）

**主题行**：`【推免申请】内蒙古大学-化学工程与工艺-前约15%-电池/〔催化方向〕方向-张三`

## 八、面试与考核实战

### 8.1 硬件清单（线上面试）

- 网络：有线优先，手机热点备用；提前测试平台（腾讯会议/钉钉/Zoom/学校专用系统）。
- 双机位按规定准备；背景整洁；灯光正面；**提前10分钟进入候考**。
- 桌面备：简历、论文、成绩单、笔和草稿纸（**被问到数据可以翻，这不丢人**）。

### 8.2 自我介绍（1分钟版框架）

> 30秒定位 + 20秒科研（两个工作的各一句话结果） + 10秒工程（竞赛） + 一句话说明"为什么来这里"。

### 8.3 高频追问速答原则

- **说数据，不说形容词**。"效果很好"→"在××条件下达到××，较对照提升××%"。
- **不知道就说不知道**。"这个我确实没有深入研究过，我的理解是…，我会下去补上" —— 比硬编强一百倍。
- **把不会的题接回自己的优势**："这块我接触不多，不过在我做的××里有一个类似的问题，我是这样处理的…"
- **被问短板**：承认 + 事实回击 + 改进行动，三段式，不要辩解。

### 8.4 反向提问（必问2—3个，提前准备）

- 课题组目前最希望推进的方向是什么？
- 研究生进组后的培养节奏大概是怎样的（前期培训、独立选题的时间点）？
- 组内对学生英语与论文产出有什么要求？
- **别问**：补助多少、能不能准时毕业、宿舍条件（这些找学长问）。

### 8.5 面试后 24 小时内必做

1. 发感谢邮件（3句话：感谢 + 复述一个你们聊到的点 + 表达期待）。
2. 把被问到的问题记进题库——**你会发现问题重复率超过60%**，第二场开始你就已经赢了。

## 九、系统周作战手册（9月18日—10月20日）

### 9.1 三个平行志愿怎么排

- 志愿**不区分先后顺序**，但**提交后48小时内不可修改**。
- 策略：**9月21日9:00 一次性填满3个**（冲1 + 稳1 + 保1），不要空着位子等——48小时锁定期意味着**早填早解锁早有第二轮机会**。
- 若某志愿48小时无回应自动解锁，立刻用它去补下一个目标。

### 9.2 时间博弈的三个决定

1. **9月21日填志愿前**：把目标按优先级排好并写下来，**不要在系统里现纠结**。
2. **9月22日起收复试通知**：**必须在规定时间内确认**，逾期作废；未确认复试通知的单位不能发待录取。
3. **9月24日14:00起可确认待录取**：**确认即锁死，不能反悔**。

### 9.3 关于"要不要等更好的offer"

**决策规则（提前定好，现场只执行）：**
- 已到手的待录取，其学校/导师在你优先级表的**前两位** → **立即确认，不要等。**
- 已到手的是"保"档，而你正在等"稳"档的结果 → **打电话给稳档导师/招生办问明确时间点**，若对方无法在你被要求的确认时限内给出结果，**就确认已到手的**。
- **不要用已到手的offer去赌一个口头承诺。** 今年优营超发、按总成绩排名录取是常态，"老师说想要你"和"系统里给你留了位"是两件事。

### 9.4 全程与导师保持实时沟通

系统周每天和已联系过的导师确认一次：**名额是否还在、是否需要我第一志愿填报、何时发复试通知**。这一步能把"信息不对称"造成的时间差压缩到最小。

## 十二、信息源与核实清单

**每件事都要以官方通知为准，以下是你必须定期查看的渠道：**

1. **中国研究生招生信息网（yz.chsi.com.cn）推免服务系统** —— 全国统一的资格备案、志愿填报、待录取确认入口，本答卷0.1节所有时间节点以此为准。
2. **目标院校研究生院官网 + 学院官网** —— 招生专业目录、推免工作办法、报名通知、拟录取公示（**拟录取公示能告诉你上年收了多少外校生**）。

4. **本科院校教务处/学院官网** —— 推免细则、名额、公示名单。
5. **各类保研信息聚合平台** —— 用于发现通知线索，**不作为决策依据**，看到后务必回到官网核实。

**必须打电话确认的三件事**（比看十页通知管用）：
- 目标单位：今年该方向是否有推免名额、是否接收外校生、英语要求的具体措辞。
