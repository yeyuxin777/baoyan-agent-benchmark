### 3.2 现有科研（主线）：目标不是"发论文"，是"做成果包"

**这是本轮最重要的认知纠正：在剩余时间不足的情况下，追求正式论文通常是负收益。**

录用周期普遍长（数月到一年以上），大概率赶不上你的任何 deadline；更糟的是，为了赶时间投一个审稿周期极短的低质量会议/期刊，风险极高——面试官一定会追问，而"有论文但讲不清/经不起问"比"坦白说还没有论文"扣分更多。

正确的目标是产出一套**成果包**，它在功能上等价于一篇 working paper：

- **一份 4–6 页的技术报告**（英文）：问题定义 → 动机 → 方法 → 实验设置 → 主结果 + 消融实验 → 局限与下一步。推免面试里这就是你的"论文"，港三申请可作为 writing sample 提交，导师推荐信也据此落笔。
- **一个可复现的产物**：开源仓库 / 系统 demo / 数据集与脚本，README 讲清如何跑出报告里的数字。这是"我真的做过"的硬证据。
- **一份 arXiv 预印本**（可选若能推进）：并非正式论文，但在港三申请和套磁邮件里能显著提升可信度与打开率。
- **三句话的研究 slogan**：面试官问"讲讲你的科研"，你要有 30 秒版本、3 分钟版本、15 分钟深挖版本（含被追问时不崩的细节）。

同时，**产出物要反过来喂给推荐信**：带着这份技术报告去找带你科研的老师，请他在推荐信里具体写你做了什么、遇到什么困难、怎么解决的。对港三和清北而言，一封具体有力的强推，价值常常高于一枚新增的区域赛奖牌。

### 3.2 专项二："为什么停了 / 还在进行中"的标准答法

这是**新信息暴露出来的最大单点风险**，也是最容易被临场答崩的地方。结构建议如下（四段式，30–60 秒）：

1. **当时的假设与目标**（一句话，说明不是随便做的）；
2. **做了什么、观察到什么**（有数字就用数字，没有就讲现象）；
3. **为什么停 / 为什么还没完**（要给出**判断**，而不是**借口**——"实验显示该路线在 X 条件下不成立，继续投入的预期收益低，所以我决定把资源转到 Y"，这叫判断；"导师太忙 / 师兄毕业了"，这叫借口，**绝对不要这样说**）；
4. **如果继续，下一步做什么**（展示你知道正确的下一步是什么）。

三条硬规则：
- **不夸大**：把"在调"说成"已基本完成"是面试里最致命的穿帮，一追问就全塌。
